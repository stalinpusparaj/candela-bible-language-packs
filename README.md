# Candela Bible language packs

Compressed, read-only Bible databases downloaded on demand by the Candela Bible app. The app verifies each unpacked database against the SHA-256 value in `manifest.json` before opening it.

## Text sources, attribution, and changes

The English World English Bible is bundled in the app. The following packs are adaptations of the Indian Revised Version texts. Each is available under Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0). The licensor does not necessarily endorse the adaptations. The manifest contains the source IDs, attribution, copyright notices, and per-text change notes.
